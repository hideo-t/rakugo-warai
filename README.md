# 高座わらい

落語の動画に、毎回ちがう客席の笑い声を自動で置くツールです。ブラウザだけで動き、動画や音声はどこにも送信されません。

## 使い方
1. `index.html` を Chrome で開く（または下の GitHub Pages のURLを開く）
2. ①で動画（MP4）を選ぶ
3. 笑い声は標準の14本（`sounds/`）が自動で読み込まれます。別の笑い声を使うときは「別の笑い声を使う」から選ぶ
4. 「自動配置」を押す → タイムラインに笑い声が並ぶ
5. 帯をドラッグで前後に移動、ダブルクリックで追加、Deleteで削除。再生して確認
6. 「笑い声トラックを書き出す」で WAV を保存
7. 動画編集ソフトで、動画の頭（0秒）にそろえて WAV を置く

## GitHub Pages で公開する
1. GitHub で新しいリポジトリを作り、`index.html` をアップロード
2. Settings → Pages → Branch を `main` / `(root)` にして Save
3. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で使えます

## 注意
- 標準の笑い声は GitHub Pages など Web 上で開いたときに読み込まれます。index.html をパソコンで直接開いた場合は、笑い声を手で選んでください
- 動画が大きすぎて読み込めない場合は、編集ソフトで音声だけ（WAV/M4A/MP3）を書き出して①で選んでください
- 40分の書き出しは約460MBのWAVになります
- 「文字起こしで判断」モードは次の版で追加予定（`placers` に関数を足す形で拡張できます）
